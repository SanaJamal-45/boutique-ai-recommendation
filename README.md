
# MiniLM Recommendation Service

AI-enhanced adaptation of the Google Online Boutique Recommendation Service for research on SLO-aware adaptive chaos engineering.

- Model: all-MiniLM-L6-v2
- Inference: ONNX Runtime (CPU)
- Communication: gRPC
- Deployment: Kubernetes (k3s)

Based on Google's Online Boutique:
https://github.com/GoogleCloudPlatform/microservices-demo
